# 生成后 QA、局部编辑与风格漂移防护

生成一次不等于通过验收。必须实际查看当前工具返回的成品，分别核对内容与风格；未看到的图片不能记为“已检查”。无法打开源图、成品或参考图时，明确哪些检查尚未完成，不声称完全保真或测试通过。

## 1. 建立可恢复的锚点

每次工作保留以下角色清晰的依据：

1. **事实源图及事实清单**：确认人数、身份、服饰、配件、动作和场景。
2. **固定风格锚点**：本 Skill 的文字标准，以及来源明确、用途已确认的风格参考；参考人物和物件不进入事实清单。
3. **用户变更清单**：只记录用户明确允许的变化，指明覆盖哪个原图属性。
4. **最后一张已验收成品**：用于后续编辑恢复，记录其对应的事实源与已生效变化。

“用户认可”记录用户选择的编辑基线，“QA 通过”记录实际检查的结果；两者分别记录，不声称用户已认可仅由执行者自检的版本。用户选定的基线存在已知错误时，保留其构图与其他认可细节，将错误单独列为待修项，不能借此擅自重画全图。

不要把“最近生成的一张”自动当作“最后已验收的一张”。失败的局部编辑可以留作对照，但不能成为下一轮的唯一事实或风格依据。若尚无通过验收的成品，使用事实源图和固定文字风格锚点重新开始。

## 2. 必须通过：内容与身份

逐项与事实源图及用户变更清单对照。

- [ ] 人物与动物数量正确，边缘和背景对象没有遗漏、复制或新增；没有把风格参考中的对象移入画面。
- [ ] 每个人都能对应到正确角色；年龄感、脸形、发型、眼镜和相对身高等关键身份锚点未交换或模板化。
- [ ] 上下装、鞋帽、主色、层次与可辨图案正确；用户没有要求的换装未发生。
- [ ] 配件属于正确人物，位置和连接关系合理；没有浮空饰品、断开的包带、漏掉的眼镜或左右错位。
- [ ] 动作、坐立状态、视线、表情、接触与手持物归属正确；没有多余肢体、明显肢体断接或为了画法而改变事件。
- [ ] 关键场景、道具、前后遮挡与光线状态保留；没有擅自补入花草、动物、贴纸、帽子、路人或其他装饰。
- [ ] 不可见细节保持概括，没有凭猜测增加具体身份标记、文字、物件或衣服图案。
- [ ] 原图清晰可辨的文字或标志没有变成虚构品牌或乱码；工具不能准确保留时，标明未通过并提出可执行修正。
- [ ] 用户指定变化已实现，且只覆盖对应对象与属性。

任一项失败都不能用“画风需要”解释为合格。对不确定事实，使用“待确认”或“无法检查”，不能勾选通过。

## 3. 必须通过：目标画风

- [ ] 人物形体是稚拙二维扁平色块，空间主要由叠放与遮挡表达；没有 3D 玩偶、黏土、塑料或动画渲染体积。
- [ ] 肤色呈暖杏橙绘本调性，并保留人物之间合理差异；脸颊是圆腮红；眼睛为简洁白眼黑瞳，服从原图视角与表情。
- [ ] 不同人物保持不同的身份与表情，不是相同五官、发型和笑容的模板。
- [ ] 头发有顺应发型、分缝或束发方向的可见笔触，不是逼真发丝或无方向噪点。
- [ ] 存在水粉式不透明底色，以及蜡笔、油画棒或彩铅的局部摩擦与叠色逻辑；不是光滑画面加一层均匀颗粒。
- [ ] 露纸、叠色、边缘和笔触疏密有自然变化；纸纹不遮盖五官与需要辨认的细节。
- [ ] 配色高饱和而柔和，具有复古气质，且未擅自改变用于辨认身份的服饰主色。
- [ ] 光线适配原场景：夜景没有变白昼，室内没有因暖调糊成一片；没有照片式皮肤、高光、景深或过度立体阴影。

一张图即使高度像源照片，只要仍是“写实插画加纹理”，就没有通过风格验收。反之，风格正确却漏人、换脸或换装，也没有通过内容验收。两个维度分别记录，不计算能互相抵消的总分。

## 4. 局部编辑的额外验收

在编辑前写下可检查的契约，见 [prompt-templates.md](prompt-templates.md)；编辑后同时对比事实源与最后验收基准。

- [ ] 点名对象与编辑区域正确，目标变化明确可见。
- [ ] 目标人物未被点名的脸、发型、衣服、动作、视线和配件保持验收状态。
- [ ] 其他人物与动物的数量、身份、穿着和位置没有变化。
- [ ] 构图、画幅、场景、道具及未编辑区域没有非预期改动。
- [ ] 局部的纸纹尺度、叠色密度、笔触方向和边缘方式与周围一致，没有贴片、光滑补丁或写实区域。
- [ ] 没有出现“修好一处、破坏另一处”的情况。若出现，整个编辑版本不作为新的验收锚点。

工具支持真实区域编辑时优先使用；只支持整图生成时，提示词中的“锁定”只是约束意图，必须检查结果，不能承诺其他像素一定不变。若无法达到必要的局部性，应如实说明限制，保留已验收基准。

## 5. 跨图片一致性

为重复出现的角色分配稳定 ID，例如 A、B、C。档案只存储已确认的身份锚点和画法，不把某张图片的偶然服饰、动作和场景固化为永久角色属性。

| 稳定项 | 随每张事实源变化的项目 |
| --- | --- |
| 身份对应、脸形概括、年龄感、经确认稳定的可辨发际线/发型特征 | 本张真实出现的服装、眼镜、帽子、包、饰品和其他临时配件；发型或年龄阶段有变化时同样服从本张事实 |
| 眼睛画法、腮红方式、头发笔触、肤色处理逻辑 | 侧脸/正脸/背影、视线、闭眼、表情、姿势 |
| 二维程度、材料体系、纸纹和笔触的大致尺度 | 日夜与室内外光线、地点、人物站位、道具和构图 |

逐张检查“同一人是否仍可辨”和“本张事实是否独立保留”。不能用统一风格为理由复制上一张服装，也不能因保持角色一致而把当前画面没有的人补进来。若年龄跨度、发型变化等使身份不确定，询问关键对应关系，不按左右位置猜人。

## 6. 风格漂移的信号与恢复

| 漂移信号 | 处理方式 |
| --- | --- |
| 越改越接近写实皮肤、复杂阴影或 3D 眼球 | 回到固定二维造型锚点，简化形体与光影；不要只增加颗粒 |
| 笔触消失，只剩全图统一噪点 | 恢复底色、局部叠色、方向性和露纸的材料关系 |
| 不同人物逐渐变成同一张脸 | 重新对照每个人的身份清单，恢复各自脸形、发型、年龄感与视线 |
| 衣服、帽子、包和道具在图间串用 | 以本张事实源重建归属，不从上一张自动补全 |
| 每轮编辑都出现新装饰、动物或人物 | 清除未获准的增添项，重新明确参考只控制画法 |
| 局部改善但全图配色、构图、脸部或质感改变 | 丢弃本轮作为基准的资格，从最后验收图重新做同一局部变化 |
| 连续编辑让原细节越来越模糊或身份越来越偏 | 停止沿退化链继续修改，回到最后验收锚点，必要时从事实源重建 |

恢复时应携带事实源、固定风格锚点与单项变化契约。不要持续把失败结果作为唯一输入，也不要用不断追加形容词替代对具体错误的修正。

## 7. 有限重试与诚实交付

1. 首次生成后执行实际查看与 QA，先处理人数、身份、服装、动作等硬性错误，再修正风格偏差。
2. 失败时选择范围最小、可检查的修正；局部问题用局部编辑，整体造型错误则回到事实源与固定风格锚点。不要为一个配件问题无目的地重做整组图片。
3. 默认每张成品最多进行 **2 轮有针对性的自动纠正**。如果同一关键问题在两轮中持续出现，停止重复尝试，说明未解决项；用户明确要求继续时可按新指示推进。
4. 每轮纠正都重新检查相关硬性项与锁定区。不得只看修正部位就宣布完成。
5. 通过验收后才将版本标为“已验收基准”。尚有硬性问题的版本只能标为草稿，不能称为完全保真、严格一致或全部通过。
6. 如果局部编辑失败而旧版合格，保留并指出最后合格版本，简要解释新变更尚未实现。若首次结果也未通过，应明确交付状态与具体缺项，不虚构成功。

可选微调包括纸纹更轻、局部笔触更疏、冷暖关系更舒适等。硬性项通过后，不为无关紧要的审美偏好无限重试；用户没有要求的微调可以直接说明为可选项。

## 8. 最小验收记录

```text
事实源：[编号]
风格锚点：[文字规范/已确认风格参考编号]
基准：[无/最后已验收编号]
本次指定变化：[无/明确列表]
实际查看：[已查看哪些输入与输出；哪些无法访问]
内容与身份：[通过/未通过/无法检查；具体项]
目标画风：[通过/未通过/无法检查；具体项]
局部锁定：[不适用/通过/未通过/无法检查；具体项]
跨图一致性：[不适用/通过/未通过/无法检查；具体项]
重试：[轮数与针对的具体问题]
最终状态：[已验收/草稿/保留旧基准；尚未完成的要求]
```

验收记录可以很简短，但必须区分实际观察、无法确认和用户明确允许的变化。不需要把每轮内部提示全部展示给用户；交付时优先说明成品、主要保真结果与尚未解决的真实限制。
