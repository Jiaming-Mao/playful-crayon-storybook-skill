# 提示词骨架

执行规则统一在 [SKILL.md](../SKILL.md)。这里仅用于组织本次输入，不另外定义画风或验收标准。方括号是待填写内容，不是应画出的文字；按任务取用字段，无需让用户填写整张表。

## 输入对应与事实

```text
事实输入：[图片编号 → 实际文件/会话图片 → 本次用途；只有文字时明确写文字设定]。
风格参考：[实际查看的 S01–S07；本次实际提交的文件/图片 ID；零张 S 时严格参考输入未完成，容量限制下的子集须注明依据]。
工具媒体映射：[每个真实媒体字段/序号 → 对应 F、B 或具体 S；无事实图片时注明文字设定，不虚构 F 图片；不把此表当作已提交证据]。
容量与缩减：[可核实的工具上限；默认提交七图，无法全传时写明本次子集与具体原因]。
编辑基线：[用户选定的成品编号；初次创作写无；已知错误另列]。
人物与动物：[数量、稳定角色 ID、画面位置，含背景/边缘可确认对象]。
逐人记录：[脸型、发型、年龄感、相对身高、表情、视线；本张衣服与可摘戴配件的颜色/款式/归属/侧别/附着；动作和握持]。
场景：[关键建筑、道具、光线、镜面/裁切等本次相关事实]。
前后与连接：[对象 A 在 B 前；手接触何处；结构可见段及遮挡；间隙背景]。
文字：[可辨内容 → 所属载体 → 位置/遮挡；不清楚则不猜]。
不确定项：[未能确认的位置与事实；关键冲突先澄清]。
本次允许变化：[用户点名的对象、属性、区域；无则为风格转译与必要二维概括]。
```

清单只用于本次工作，不自动画成文字，也不把个人信息写入公开示例。

## 首次转绘或文字原创

```text
任务：[将事实图编号转绘 / 依据用户文字创作]。
[本次事实与允许变化。]
按已读取的 SKILL.md 第 2 节组织造型、色彩、材料与排除项；风格参考只提供画法。
本次真实图片输入：[按媒体顺序逐张标明 F/B/S]。只有 F/文字事实决定内容；S 中人物、衣服、道具、地点、文字和构图不进入本次事实。
沿用 S 中的二维人物概括、方向性头发笔触、不透明水粉底层、蜡笔/油画棒叠色、自然露纸与不规则边缘；不把本图重画成光滑实心发片、均匀肤色和规整勾线的人物。
把本次容易出错的关系明确写入：[人数/配件归属/前后/结构/文字载体等，按需选择]。
除指定变化外保留事实，不自动添加标题、签名、水印、角色或装饰。
构图与画幅：[原构图或用户指定要求]。
按 SKILL.md 第 6 节实际查看并分别验收。
```

不要只向图像工具发送“参见 SKILL.md”，而工具实际读不到文件；将已读取规范中本次所需的画风和约束组织成工具可用的指令，并把所需 F/B 和 S 实际放入本次媒体字段。只能传原图或纯文字时，不将该调用标为严格参考成功。这里只省略固定文案的重复维护，不省略调用时的信息。

## 局部编辑与纠偏

```text
基线：[用户认可版本]；事实依据：[源图或明确文字要求]。
目标：[角色 ID/唯一对象及可见位置；分清身体左右与画面左右]。
允许变化：[具体属性]；区域：[目标及必要相邻边界]。
必要连带调整：[连接、遮挡或背景过渡；没有则无]。
锁定：[目标未点名属性、其他人、背景、构图/画幅、配色和材料尺度]。
本次实际媒体：[B/F 与授权 S 的顺序和角色，按真实接口提交；未传入的图片不声称工具已收到]。
已观察到的问题：[具体错误；不写未经查看的推断]。
执行规则：[按单一规范取用相关风格、结构、文字层级及恢复规则]。
检查目标、整图锁定项和画风；不能只看编辑位置就宣布成功。
```

只改变物体前后关系时，也应写明哪些可见段被谁遮挡、手在哪里接触；不要通过改变人体比例把物体“补完整”。背景文字修改只改变获准的文字或载体属性，保持人物遮挡。

## 系列任务

```text
共同角色：[稳定 ID → 经确认的身份锚点]；风格基准：[编号/文字规范]。
本张：[图片编号与实际输入对应]。
本张独立事实：[本图人数、服装/眼镜等临时配件、动作、年龄阶段、场景和光线]。
允许变化：[本次指定项]。
画法复用同一规范；内容取自本张，不从上一张补入衣服、道具或缺席角色。
本次生图仍提交对应 F/B 与 S，不能假定上一次调用的媒体自动延续。
```
