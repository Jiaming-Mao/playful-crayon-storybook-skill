# 童趣蜡笔手绘绘本风：风格规范

本文件把用户已确认的对话文字要求转成可执行标准，并与本次逐张核查的 7 张已授权正向成品交叉对照；2 张反面案例只抽象为文字排除规则，不收录反例图片。逐图观察、文件来源及授权范围见 [正向成品参考](positive-examples.md)。未来执行者仍须实际打开所用参考图，不能仅因仓库存在图片便声称已看过。

## 1. 目标画面

把真实人物与生活场景转译为稚拙、亲切、有手绘痕迹的二维绘本插画。人物像画在纸上的色块和笔触组成，既保留原图中“是谁、穿什么、在做什么”，又具有统一的暖色皮肤、夸张眼睛、圆腮红与真实叠色。

“稚拙”体现为概括、略有不规则的轮廓、宽松比例和自然落笔，不等于五官随意复制、肢体错误、遮挡关系混乱或丢失人物身份。画面可以可爱，但不能把不同年龄、不同脸型的人全部改成同一个模板娃娃。

## 2. 人物造型

### 轮廓与比例

- 以二维扁平色块构成头、躯干和四肢；可适度概括比例，保持原图人物之间的身高、体量和年龄差异。
- 轮廓轻微不规整，有手部控制的节奏；避免光滑矢量描边、精确机械曲线和所有物体统一粗边。
- 原图的发际线、脸形、刘海分区、眼镜轮廓、显著表情等是身份锚点。先保留差异，再统一画风。
- 原图看不清的面部细节可以概括，不能凭空补出具体痣、伤疤、牙齿、饰品或其他身份特征。

### 皮肤、脸颊与眼睛

- 皮肤以暖杏色、杏橙色为主，形成绘本式暖调；保留人物之间可见的肤色深浅差异，不把全部人物处理成完全相同的脸。
- 圆形腮红清楚可见，与皮肤色块自然叠合；避免照片式高光、毛孔、写实化妆与立体美容滤镜。
- 眼睛使用较大的白色眼形与简洁黑瞳，保留原图的视线方向和表情关系。允许随侧脸、眯眼、闭眼、眼镜遮挡调整，不强行给所有角度画正面大眼。
- 鼻、嘴使用少量线条或简洁色块。微笑、张嘴、抿嘴等区别来自原图，不能给所有人物统一露齿笑。

### 头发与衣服

- 头发先确立发型大色块，再叠加沿生长方向、卷曲方向或束发方向的可见笔触。笔触应解释发型，不能变成均匀的毛毡噪点。
- 保留头发长短、分缝、刘海、马尾或发髻位置，以及原图可辨认的发饰；不增加蝴蝶结、花朵、帽子。
- 衣服保持原图中的类别、主色、层次、领口、袖长、图案位置和可辨配件。材质可概括为手绘色块，服饰事实不可随画风随意改变。
- 色彩可在同一色相家族内作绘本化调整，但不能把辨认人物所需的红衣改成蓝衣，或把格纹、条纹、标志性图案全部消除。

## 3. 真实材料逻辑

目标是“在纸上用材料画出来”的感觉，而不是完成一张光滑图后覆盖颗粒。

1. **底层**：水粉式或不透明颜料式的大色块，形体平面化，边缘有轻微手绘起伏。
2. **叠色**：蜡笔、油画棒和彩色铅笔留下局部摩擦、交叠、短线、干笔或反复铺色的痕迹。不同材料共同服务同一张画，不能像拼贴互不相关的滤镜。
3. **露纸**：局部颜色未完全盖实，露出少量自然纸白或暖纸色；疏密随笔触和受力变化。
4. **纸张**：柔和的纤维或细纹作为承载面，存在于画面整体，但不盖住五官、衣服细节或文字。

笔触随对象变化：头发有方向，衣服有铺色块面，背景可以更宽松，腮红可以反复轻擦。避免所有区域同频率、同尺度的噪点；避免塑料、金属光泽和橡皮泥表面。材质不能成为遮掩变形手指、错误衣服、脸部失真的借口。

## 4. 色彩与空间

- 使用高饱和但柔和的复古配色：暖橙、杏色、番茄红、复古蓝、草绿、奶油黄等可以构成主调，但实际配色仍服从源图和用户要求。
- 大色块关系明确，以少量冷暖对比建立层次；不要用大片灰褐脏色消灭童趣，也不要用荧光色和过强锐化制造刺激。
- 空间以平面叠放、尺寸关系、遮挡和简洁地面表达；允许少量概括阴影，不依赖真实透视、复杂体积光和照片式景深。
- 原图场景是内容依据。可以简化细碎背景，但应保留能识别地点和事件的主体、相对位置及互动关系。
- 不自动添加彩虹、星星、花草、爱心、贴纸、动物、围观者或装饰性道具。只有用户明确指定的增添项才能进入变更清单。

### 不同光线条件

| 场景 | 保留的事实 | 画风适配 |
| --- | --- | --- |
| 日间户外 | 光照方向、主要景物和原图色彩关系 | 用明快但柔和的大色块，保留少量纸白与暖杏肤色 |
| 夜间或暗处 | 夜色、灯光来源、可见与不可见的范围 | 用复古深蓝、紫蓝或暖暗色组织背景，人物仍为二维暖色块；不改成白昼，不画真实发光皮肤 |
| 室内暖光 | 室内陈设、衣服原色与位置关系 | 暖底色配少量冷色平衡，避免全图橙黄导致衣服和肤色混在一起 |
| 逆光或局部遮挡 | 能确认的轮廓与遮挡 | 概括阴影与暗部，不补出不可见的衣服图案、五官或手中物品 |

## 5. 内容保真与变更优先级

风格参考控制画法，事实源图控制内容，用户明确要求控制指定变化。三个角色不能互换。

执行时为每张输入分配一个角色：

- **事实源图**：确定人物与动物数量、身份、服装、配饰、动作、视线、物件和场景。
- **风格参考**：只确定造型语言、色彩处理、材料和画面气质。不能把参考图的人物、衣服、动物、道具、文字或场景带入事实源图。
- **已验收基准画**：用于后续局部编辑的画风、构图和未修改区域锁定。若基准画与事实源图有误差，不能把误差自动升级为事实。
- **用户指定变化**：列出本次获准改变的对象和范围。例如“只把 A 的帽子改成红色”；该项可以覆盖原图对应事实，其他事实仍锁定。

没有事实源图时，可以按用户的文字设定创作原创场景；不要声称人物、穿着或数量是从未提供的照片中识别出来的。输入冲突涉及人物身份、数量或必要配件时，应先澄清；不影响其他工作的部分可以继续整理。

### 必须逐项保留的内容

| 项目 | 需要核对的事实 | 常见错误 |
| --- | --- | --- |
| 人物与动物数量 | 包括边缘、背景和部分遮挡对象；无法判断的模糊形状不擅自认定为人或动物 | 漏人、复制人、添加宠物或把背景图案画成动物 |
| 身份 | 每个人的脸形、发型、年龄感、身高关系、眼镜和可辨特征 | 所有人共用一张脸、角色互换、儿童成人化 |
| 服饰 | 上下装、外套、鞋帽、主色、层次及可见图案 | 为画面配色擅自换衣服、给不同人交换服装 |
| 配件附着 | 谁佩戴、戴在哪一侧、与身体或衣服如何连接；包带与包、眼镜与脸的关系 | 浮空饰品、缺失包带、左右颠倒、把配件移给别人 |
| 动作与接触 | 肢体方向、坐立状态、牵手、拥抱、手持物及物体归属 | 为方便画法改姿势、错手、物体悬空、接触断开 |
| 视线与表情 | 看向谁、看向哪里，闭眼或侧脸等状态 | 所有人看镜头、把互动改成合照姿势 |
| 场景 | 关键建筑、桌椅、标识、地面和前后遮挡关系 | 擅自换地点、补装饰、擦掉事件所需道具 |
| 文字与标志 | 原图可清楚辨认的内容及位置 | 虚构品牌或乱码；清晰文字不能准确保留时，应明确说明并请求局部修正 |

被遮住的身体、手、衣服、标志或物品不应被“合理想象”成具体细节。可以沿已知轮廓概括连接，但不得借此改变姿势、增加手持物或编造可辨认内容。

## 6. 正反对照规则

以下是抽象执行对照，不复制或展示反例图片。

| 目标方向 | 应排除的替代方案 |
| --- | --- |
| 稚拙二维人物、简洁平面形体 | 3D 动画角色、立体玩偶、黏土或塑料质感 |
| 暖杏橙皮肤、圆腮红、白眼黑瞳 | 写实人像换色后加腮红；眼睛有玻璃球反光和复杂虹膜 |
| 身份各异但属于同一画风 | 模板脸、统一发型、统一笑容、人人相同比例 |
| 头发有方向性短线与色层 | 平滑发片、逼真发丝渲染、均匀毛糙噪点 |
| 颜料底层与蜡笔、油画棒、彩铅的可见叠色 | 光滑矢量图加全局颗粒；写实插画覆盖纸纹滤镜 |
| 高饱和而柔和的复古色块 | 荧光配色、塑料高光、过曝、污浊灰褐色全覆盖 |
| 以源图事实为基础的场景简化 | 从风格参考搬入人物、动物、帽子、花草或场景 |
| 局部修改后其他区域保持验收状态 | 每次编辑都重新解释全画，逐轮变脸、换服装、丢纹理 |

两个主要反面方向分别是：**写实插画叠加噪点或纸纹**，以及 **3D 动画式立体造型**。排除它们时，要重建人物的平面造型与材料逻辑，不能只减少高光或提高颗粒强度。

## 7. 风格与相似度分开判断

每次验收都分别回答两个问题：

1. **事实与身份是否保真？** 人物数量、身份、衣服、配件、动作和场景是否正确。
2. **是否达到目标画风？** 是否形成二维造型、暖杏肤色、圆腮红、白眼黑瞳、方向性头发与真实材料叠色。

风格漂亮不能抵消人物错误，像原图也不能抵消写实滤镜或 3D 偏移。若两者发生冲突，重新设计简化方式或修正提示，不通过“增强风格”掩盖身份错误。局部编辑与完整 QA 见 [qa-and-drift.md](qa-and-drift.md)，具体提示词见 [prompt-templates.md](prompt-templates.md)。
