## 1. Skill 与包完整性

使用 skill-creator 的 `quick_validate.py` 检查 SKILL.md 前置元数据与未完成脚手架；使用 YAML 解析器检查界面元数据及调用名。包检查脚本核对全部相对链接、公开文件类型、7 张图片的固定白名单、SHA-256、尺寸、字节数、PNG 块 CRC 与附加元数据。

可重跑：

```sh
python3 scripts/validate_package.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

自动回归测试使用临时目录副本，不修改工作包：

| 测试 | 应有行为 |
| --- | --- |
| 原始已审核包 | 接受 |
| 正向图字节被修改 | 拒绝 |
| 加入第 8 张未审核图片 | 拒绝 |
| 文档本地链接失效 | 拒绝 |
| PNG 加入文本元数据，且同步更新哈希 | 仍拒绝 |
| 文档链接指向包外本地文件 | 拒绝 |

执行结果：Skill 官方校验通过，界面元数据校验通过，20 个发布文件的包完整性检查通过，6/6 自动回归测试通过。

检查脚本不能判断未来新增素材是否真正获准公开，图片授权仍须人工核实。固定白名单与哈希也不能证明生成模型画风或保真达标。

## 2. 独立提示词与决策演练

独立评估者读取 Skill 与相关参考，以虚构文字描述为唯一事实输入，为以下六种请求实际组织生成/编辑提示词或处理决定。未把文字描述伪称为已查看照片，未在此环节生成或查看成品。

| 场景 | 演练所得行为 |
| --- | --- |
| 三人夜街原照描述，风格参考是六人并带星星 | 保留三人和各自眼镜/胸针/丝巾归属，禁止把参考人数、星星移入结果 |
| 只修儿童胸针，上轮失败改坏成人眼镜与丝巾 | 回到用户认可的旧基线，限定胸针区域并全图复核锁定项 |
| 确认是同一人，两图衣服和眼镜不同，第二图少一人 | 保持画法与身份，逐图保留服装、是否戴眼镜和人数；不补入缺席角色 |
| 原图两人，用户明确要求中间加一只小狗 | 允许两人加一狗，只解除这项内容锁定 |
| 来源、类别与公开授权不明的图片拟加入示例库 | 核实前不公开、不写入授权清单 |
| 没有图像生成工具，已有结果又无法打开 | 给出实际可用提示词与待核查项，明确尚未生成/核查，不假报成功 |

初次演练发现模板把“眼镜”举作稳定身份锚点，可能与逐图穿戴事实冲突。现已改为逐图记录可摘戴配件；评估者复读并重演第三项，确认第一图红外套戴眼镜、第二图蓝裙无眼镜且少一人的决定一致。另明确了人物自身左右与画面左右、用户认可与 QA 通过的区分，以及只有照片转述时的执行边界。

这些结果验证指令的可执行性，不能证明图片模型实际保留了照片身份、服饰、动作或局部像素。

## 3. 实际文字出图测试

使用内置 imagegen，从虚构文字设定生成一张测试图；没有上传任何私人照片，也没有把测试图加入公开示例集。

测试内容：恰好两人。画面左侧成人，长椭圆脸、短深棕侧分头发、蓝色圆眼镜、红外套、奶油色内搭、深裤子，望向儿童。画面右侧儿童，圆脸、齐刘海、黄 T 恤、黑裙、红鞋，双臂自然下垂；儿童自身左胸（画面右侧）有一枚紫色圆胸针。背景仅浅蓝墙与奶油色地面，不加人物、动物、星星或文字。

提示词使用本 Skill 的二维扁平造型、暖杏橙肤色、圆腮红、白眼黑瞳、方向性头发、局部蜡笔/油画棒与水粉叠色、纸色留白、柔和复古色彩及排除项。

实际查看结果：两人数量正确，成人与儿童脸形/身高有差异，衣服配色和眼镜正确，紫色圆胸针附着在指定侧，视线和垂臂姿态符合设定；没有新增动物、装饰或文字。造型为二维，头发与衣服有方向性笔触，存在叠色、局部露纸及手画边缘，没有明显 3D 或写实图叠颗粒的偏移。本张文字设定测试通过。

此测试没有原始照片，因此不证明真实人物身份相似度、真实照片转绘保真或复杂多人照片效果；也不证明跨图一致性可以自动保证。7 张历史正向示例仅验证其已授权成品分类与风格，不替代原照对比。

## 4. 实际局部编辑测试

将第三节的生成图实际传入内置 imagegen 编辑，唯一变化为“儿童左胸紫色圆胸针改为复古草绿色”，明确锁定两人脸部、眼镜、衣服、动作、背景、构图与手绘材料。

实际查看：圆胸针在原位置变绿；人数、眼镜、红外套、黄 T 恤、黑裙、红鞋、人物姿态与画面构图保持，未出现新增对象或明显 3D/写实偏移。两图均为 1254×1254。目标变化与主要内容锁定通过本次视觉检查。

限制：区域外笔触和纸纹存在细微重绘。输出不能认定为区域外像素完全不变，也不能将一次视觉检查推广为所有局部编辑都可保证。Skill 因此明确区分视觉锁定与真实像素锁定，要求每次编辑检查整图，并在出现实质变化时回到最近认可基线。此测试不是私人照片身份保真测试；测试图不在公开资产清单中。
